# 😊 Age Sentiment Analysis

This project performs **sentiment analysis across different age groups** using **TextBlob** and Natural Language Processing (NLP).

The notebook analyzes emotional text with emojis and classifies sentiments into:

- Positive 😊
- Negative 😔
- Neutral 😐

##  Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- TextBlob

## 📊 Features
- Age-based sentiment analysis
- Sentiment polarity calculation
- Emotion classification
- Data visualization using charts

## 🚀 How to Run

Install dependencies:

```bash
pip install pandas numpy matplotlib textblob
```

Run the notebook:

```bash
jupyter notebook
```

Open:

```bash
age-sentiment-analysis.ipynb
```

## ⭐ Project Goal
To understand emotional sentiment patterns across different age groups using NLP techniques.
